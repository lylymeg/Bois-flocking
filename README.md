# 🦅 Boids Flocking Simulation (Pygame)

Une simulation classique d'**intelligence en essaim (*Swarm Intelligence*)** basée sur le modèle des *Boids* de Craig Reynolds, développée en **Python** avec **Pygame**.

---

## 📸 Fonctionnalités

- 📐 **3 Règles Fondamentales :** Séparation, alignement et cohésion calculées dynamiquement pour chaque agent en temps réel.
- 🖱️ **Interactivité fluide :** L'essaim entier suit et réagit aux déplacements de ton curseur sur l'écran.
- ➕ **Ajout de population :** Appuie sur la barre d'espace pour injecter de nouveaux boids dans la simulation.
- 🔄 **Réinitialisation rapide :** Remets à zéro l'essaim avec la touche `R`.
